- **After any measured surprise**: when a finding contradicts our doctrine, sweep for how other leagues handled the same shape.
- **Topic selection comes from the wheel in `docs/research/tactics/INDEX.md`**, which records what has already been swept so successive sessions do not re-research the same ground. Update the index in the same commit as the findings.

Output contract for sweeps: every tactic lands in `docs/research/tactics/` as a file with the frontmatter in INDEX.md — source URL, evidence strength (documented / anecdotal / inference), and an explicit **transferability verdict against our actual ruleset**. An untransferable tactic recorded as untransferable is a useful result; a plausible-sounding one with no source is pollution. Never invent a tactic or attribute one to a team that did not use it.
