# Florent Code League 2026

Our entry in the Florent Code League — an autonomous bot competing on a live Nordic ladder.

Source: https://code.florent.vc/ · Platform: https://game.code.florent.vc (registration required)

## What we know so far

From the public page only — the real docs are behind registration.

- Write code controlling an autonomous system that runs unattended in a live arena.
- Objectives: secure resources, expand territory, coordinate at scale, adapt in real time.
- Single live leaderboard across the Nordics. Top 16 teams qualify for the Stockholm finals.
- €20K prize pool across category winners.
- Ships with a starter bot and short interactive tutorials.

Unknown: language(s), API shape, tick/turn model, match length, how submissions and
ranking actually work. Fill in `docs/game-model.md` the moment we get access.
