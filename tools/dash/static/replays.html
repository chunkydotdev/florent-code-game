How to read this

The list comes from a background scan of replay_archive/ (tools/dash/replays.py, refreshed every 60s — a full scan of the directory takes a couple of seconds, too slow to pay on every page load, so the line above shows the scan's own age). Map size, winner and win condition per game are read lazily — only for the rows this page actually shows, with a cheap top-level-only parse (replay_view.peek_outcome) rather than the full per-round replay the viewer itself does. A game chip with no color means it has not been decoded yet (hover for why); it still opens the viewer.

This page computes nothing. No win rate, no aggregation across matches. It lists files and opens the viewer on click.
