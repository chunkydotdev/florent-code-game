Battery shards

Every shard on this box, run and running. Click a row for its detail.

Every state, row count, percentage, heartbeat age, ETA, rate and band on this page is read out of tools/corefill_status.sh, not recomputed here. That tool is the authority on STALLED (alive but frozen) vs DEAD (started, no process), and it refuses to print a win rate under 400 rows because the band there is wider than any effect we chase. This page inherits the refusal instead of putting a tempting number beside n=41. tools/dash/shard_diffcheck.py re-parses the same text with a different implementation and fails on any disagreement.

Artefacts with no worklist line

corefill_status.sh iterates the worklist, so these shards — whose lines were replaced by later batches — are not covered by the authority. This page therefore prints no state, no rows and no rate for them; only the artefacts they left on disk. Deriving those numbers here would be a second copy of the computation, which is the one thing this view is not allowed to be.
